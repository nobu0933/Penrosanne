# Penrosanne ルール仕様（草案）

## 1. 概要

Penrosanne は、プレイヤーが地形の描かれたペンローズひし形タイルを盤面に配置し、地形を完成させて得点を競うゲームである。正方形グリッドではなく、薄いひし形（シン）・厚いひし形（ファット）による非周期的な盤面を特徴とする。

本書は初期実装向けの基本ルールである。既存の商用ゲームの固有名称・固有意匠・画像・文章は使用しない。

## 2. 人数と勝利条件

- プレイ人数：1〜4人（ソロはプレイヤー1人とCPU 1〜3人）
- 各プレイヤーは同数の地形コマを持つ。初期数は **7個** とし、ゲーム開始前の設定で変更できる。
- 山札がなくなり、全プレイヤーが最後のタイルを処理したらゲーム終了。
- 得点が最も高いプレイヤーが勝者。同点の場合は共有勝利とする。

## 3. 地形とタイル

初期版の地形は以下の4種とする。

| 地形   | 説明                     | 完成条件（基本）                    |
| ------ | ------------------------ | ----------------------------------- |
| 都市   | 壁で囲まれた領域         | 開いた都市の辺がなくなる            |
| 道     | タイルの辺を結ぶ経路     | 道の開いた端がなくなる              |
| 草原   | 都市・道以外の領域       | ゲーム中には完成しない              |
| 修道院 | タイル中央にある特殊地形 | 4頂点すべての周囲が他タイルで埋まる |

初期版のタイルは、薄いひし形（シン）と厚いひし形（ファット）である。各辺には都市（`C`）、道（`R`）、草原（`F`）のいずれか1種だけを割り当てる。タイル内の同じ地形どうしがつながるか、または分離するかは特徴領域として別に定義する。詳細は `docs/tile-system.md` を参照する。

## 4. 手番

手番は時計回りに進行する。各手番は次の順で処理する。

1. 山札からタイルを1枚引く。
2. 頂点型だけによる事前探索で、確定配置だけを薄い灰色の実線で盤面へ表示する。
3. 開始時設定が `once` なら必要に応じて各プレイヤー1回だけ、`unlimited` なら候補上で何度でも、引いた未配置タイルの地形を左右反転する。
4. 手元タイルの地形が接続する候補を選び、盤面に合法的に配置する。
5. 希望する場合、今置いたタイル上の地形1つに自分のコマを1個置く。
6. 完成した都市・道を確認し、得点とコマの返却を行う。
7. 次のプレイヤーへ手番を渡す。

手元のコマがない場合、または今置いたタイルにコマを置ける合法な特徴領域が1つもない場合は、ミープル配置を省略して次のプレイヤーへ手番を渡す。

引いたタイルに合法的な配置場所がない場合は、そのタイルを除外して次のタイルを引く。除外タイルはゲーム終了時の得点には影響しない。

各プレイヤーは対局中に1回だけ、未配置の手札タイルを引き直せる。引き直したタイルは山札へ戻してシャッフルし、新しいタイルを1枚引く。引き直し後のタイルも合法配置できない場合は、通常どおり除外して次のタイルを引く。

開始時に地形の左右反転を `once` または `unlimited` から選ぶ。`once` では各プレイヤーは対局中に1回だけ、引いた未配置タイルを左右反転できる。`unlimited` では通常地形・左右反転地形の両方を候補として判定し、仮置き後にどちらも合法なら反転ボタンで選べる。反転地形にも通常の辺記号・頂点型・地形接続・空白防止の配置規則を適用する。タイル配置の確定後には反転できない。反転と地形の180度回転は独立であり、通常・反転のみ・180度回転のみ・反転かつ180度回転の4状態を判定する。反転後に引き直す場合、反転タイルを元の向きに戻して山札へ戻し、次に引くタイルは反転されていないものとする。

## 5. タイルの合法配置

タイルの配置は、次をすべて満たすとき合法である。

- 少なくとも1辺が既存タイルの辺と完全に接している。
- 各隣接辺で、同じ系列（alpha/beta）かつ反対の形状（convex/concave）の辺記号が接続する。通常・180度回転を判定するモードでは、各タイルの整合するパターン候補を保持し、周囲の辺記号・頂点型によって候補が1つになった時点で確定する。
- 開始前設定で有効なら、地形・特徴領域（都市・道・草原・道路終点・ミープルアンカー）だけをタイル中心回りに180度回転した状態も判定する。これは辺記号パターンとは独立であり、通常、辺記号のみ180度回転、地形のみ180度回転、両方180度回転の4状態が候補になり得る。
- 地形の左右反転が `unlimited` のときは、通常・左右反転の両地形を判定する。地形の180度回転とも独立であり、通常、反転のみ、180度回転のみ、反転かつ180度回転の4状態が候補になり得る。
- タイルどうしが面積を持って重ならない。
- タイルの頂点だけが触れている状態は、隣接・接続とはみなさない。
- 各頂点で、タイルが実際に占める角度と頂点型のスロットを照合する。連続して接する頂点名は許可された頂点型の循環連続部分列になり、未配置の扇形を挟む頂点名どうしは連結しない。
- 上の形状マッチングを満たした候補について、空白防止（絶対禁則）を判定する。
- 最後に、接するすべての辺で地形の種類が一致することを判定する。道と道は必ず接続できる。

手元タイルの地形判定より先に、地形を持たない仮想タイルで**ルール3の頂点型だけ**を増分探索する。この事前探索では辺記号（ルール2）・地形・空白防止（ルール1）を用いない。頂点列は `C`、`AA`／`FH`／`HF`／`BH`／`FD`、`AEE`／`EEA`／`EAE`／`DGG`／`GGB`、4枚の `EEEE`／`DGGG`／`GGGB`／`BDGB`／`DGBD`／`DGGB` の順に調べる。`DGG` と `GGB` は king・queen のどちらかは未確定だが、全完成形に共通する配置は確定する（それぞれ `GBDGG`、`GGBDG` まで）。これらの識別列は頂点列全体との一致ではなく、時計回りの連続部分として**含まれた時点で**対応する型を確定する（例: `HC` は star、`GBH` は ace）。型の完成方法が複数ある場合でも、全完成方法に共通するタイル位置は確定配置として仮想的に追加し、そのタイルの4頂点だけを続けて再評価する。確定配置は薄い灰色の実線で表示し、未確定配置は記録・表示しない。手元タイルは通常の全ルールで判定した候補から、確定配置と異なる位置で面積が重なるものを除外する。

### 空白防止（禁則配置）

通常のカルカソンヌでは、道・都市などの地形接続を満たせば、原則として任意の位置にタイルを配置できる。本ゲームでは、通常の地形接続とは別に、ペンローズタイルの辺記号・頂点型によるマッチング規則も満たす必要がある。

ただし、マッチング規則だけでは、ペンローズタイルの非周期的な敷き詰めの性質により、周囲のタイルが干渉して、シン・ファットのどちらを使っても埋められないデッドエンド（敷き詰め不可能な空白領域）が生じ得る。

空白防止は地形と山札内のカード構成を考慮せず、形状と重なりだけを使う。**絶対禁則配置**とは、配置後の空き辺のいずれかで、シン・ファットのどちらを置いても既存タイルと重なってしまう配置である。絶対禁則配置は候補から常に除外する。

この制約により1ターンあたりの配置の自由度は下がるが、デッドエンドの発生確率を低減し、終盤まで美しい敷き詰めを維持しやすくする。完全な防止を保証するものではなく、この条件の下でも敷き詰め不可能な領域が生じる可能性は残る。ただし通常のデッドエンドより発生しにくく、デッドエンドを戦略に組み込むには相当の熟練を要する。

現在のタイルに通常候補がない場合、そのカードは破棄し、デッキへ戻さずに次のカードを引く。

複数の既存タイルと接する候補では、上記のすべての接続条件を同時に満たさなければならない。

最初のタイルは開始タイルとしてランダムに1枚選び、盤面中央に配置する。開始時点では辺記号パターンは未確定とする。

## 6. コマの配置

- コマは、今置いたタイルに描かれた都市・道・草原のいずれか1領域にだけ置ける。
- 接続済みの同一地形領域に、すでに誰かのコマがある場合、その領域には置けない。
- コマを置かないことも選べる。
- 完成した都市・道・修道院は得点化後にコマを持ち主へ返す。草原はゲーム終了時まで返さない。

草原についても都市・道と同様に、タイルをまたいで接続している草原領域全体で占有を判定する。草原の接続範囲はタイルを4小領域に分割した定義に基づいて求める。自分を含むいずれかのプレイヤーのコマがすでにある草原領域には、追加でコマを置けない。

## 7. 得点

都市・道・修道院・草原の完成条件と得点の詳細は `docs/scoring.md` を正とする。

## 8. ゲーム終了時の得点

- 未完成の都市・道に置かれたコマは、それぞれの終局得点を得る。
- 草原のコマは、隣接する完成都市1つにつき3点を得る。
- 草原のコマは終局採点後も盤面に残す（結果表示用）。

## 9. 頂点チップ

タイルの配置によって盤面上の頂点の周囲がすべてタイルで満たされたとき、そのタイルを配置したプレイヤーは頂点チップを1枚得る。同じ頂点から得られるチップは1枚だけとする。色の区別はなく、獲得個数だけを記録する。チップは終局得点の要素として表示・保持するが、初期版では得点換算を行わない。

## 10. 今後の拡張候補

- 修道院・庭園などの特殊地形
- 紋章、交差点、橋などの得点修正
- 草原の終局得点
- タイルごとの希少度・追加タイルセット
