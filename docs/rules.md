# Penrosanne ルール仕様（草案）

## 1. 概要

Penrosanne は、プレイヤーが地形の描かれたペンローズひし形タイルを盤面に配置し、地形を完成させて得点を競うゲームである。正方形グリッドではなく、薄いひし形（シン）・厚いひし形（ファット）による非周期的な盤面を特徴とする。

本書は初期実装向けの基本ルールである。既存の商用ゲームの固有名称・固有意匠・画像・文章は使用しない。

## 2. 人数と勝利条件

- プレイ人数：1〜4人（ソロはプレイヤー1人とCPU 1〜3人）
- 各プレイヤーは同数の地形コマを持つ。初期数は **7個** とし、ゲーム開始前の設定で変更できる。
- 山札がなくなり、全プレイヤーが最後のタイルを処理したらゲーム終了。
- 得点が最も高いプレイヤーが勝者。同点の場合は共有勝利とする。

## 3. 地形とタイル

初期版の地形は以下の4種とする。

| 地形 | 説明 | 完成条件（基本） |
| --- | --- | --- |
| 都市 | 壁で囲まれた領域 | 開いた都市の辺がなくなる |
| 道 | タイルの辺を結ぶ経路 | 道の開いた端がなくなる |
| 草原 | 都市・道以外の領域 | ゲーム中には完成しない |
| 修道院 | タイル中央にある特殊地形 | 4頂点すべての周囲が他タイルで埋まる |

初期版のタイルは、薄いひし形（シン）と厚いひし形（ファット）である。各辺には都市（`C`）、道（`R`）、草原（`F`）のいずれか1種だけを割り当てる。タイル内の同じ地形どうしがつながるか、または分離するかは特徴領域として別に定義する。詳細は `docs/tile-system.md` を参照する。

## 4. 手番

手番は時計回りに進行する。各手番は次の順で処理する。

1. 山札からタイルを1枚引く。
2. 必要なら、手番中に1回だけ引いた未配置タイルを左右反転する。
3. タイルを回転させ、盤面に合法的に配置する。
4. 希望する場合、今置いたタイル上の地形1つに自分のコマを1個置く。
5. 完成した都市・道を確認し、得点とコマの返却を行う。
6. 次のプレイヤーへ手番を渡す。

手元のコマがない場合、または今置いたタイルにコマを置ける合法な特徴領域が1つもない場合は、手順3の確認を省略して手順4へ進む。

引いたタイルに合法的な配置場所がない場合は、そのタイルを除外して次のタイルを引く。除外タイルはゲーム終了時の得点には影響しない。

各プレイヤーは対局中に1回だけ、未配置の手札タイルを引き直せる。引き直したタイルは山札へ戻してシャッフルし、新しいタイルを1枚引く。引き直し後のタイルも合法配置できない場合は、通常どおり除外して次のタイルを引く。

各プレイヤーは対局中に1回だけ、引いた未配置タイルを左右反転できる。反転タイルにも通常の辺矢印マッチング・地形接続・空白防止の配置規則を適用する。タイル配置の確定後には反転できない。反転後に引き直す場合、反転タイルを元の向きに戻して山札へ戻し、次に引くタイルは反転されていないものとする。

## 5. タイルの合法配置

タイルの配置は、次をすべて満たすとき合法である。

- 少なくとも1辺が既存タイルの辺と完全に接している。
- 各隣接辺で、矢印が同じ物理方向へ連続し、矢じり数が一致する。未配置タイルは通常・上下反転の両パターンを検査し、いずれか一方が周囲のすべての辺と整合しなければならない。
- タイルどうしが面積を持って重ならない。
- タイルの頂点だけが触れている状態は、隣接・接続とはみなさない。
- 上の形状マッチングを満たした候補について、空白防止（禁則配置）を判定する。
- 最後に、接するすべての辺で地形の種類が一致することを判定する。道と道は必ず接続できる。

### 空白防止（禁則配置）

通常のカルカソンヌでは、道・都市などの地形接続を満たせば、原則として任意の位置にタイルを配置できる。本ゲームでは、通常の地形接続とは別に、ペンローズタイルの辺矢印によるマッチング規則も満たす必要がある。

ただし、マッチング規則だけでは、ペンローズタイルの非周期的な敷き詰めの性質により、周囲のタイルが干渉して、シン・ファットのどちらを使っても埋められないデッドエンド（敷き詰め不可能な空白領域）が生じ得る。

空白防止は地形と山札内のカード構成を考慮せず、形状・重なり・辺矢印だけを使う。禁則は次の2種類に分ける。

- **絶対禁則配置**: 配置後の空き辺のいずれかで、シン・ファットのどちらを置いても既存タイルと重なってしまう配置。候補から常に除外する。
- **相対禁則配置**: 重ならずに置ける形状はあるが、辺矢印のマッチングを満たす形状がない空き辺を生む配置。通常候補とは別に紫色で表示し、各プレイヤーは対局中に1回だけ配置できる。

この制約により1ターンあたりの配置の自由度は下がるが、デッドエンドの発生確率を低減し、終盤まで美しい敷き詰めを維持しやすくする。完全な防止を保証するものではなく、この条件の下でも敷き詰め不可能な領域が生じる可能性は残る。ただし通常のデッドエンドより発生しにくく、デッドエンドを戦略に組み込むには相当の熟練を要する。

すでに相対禁則となっている空き辺は、次手番の候補を相対禁則にする理由にはしない。新たに相対禁則を生む場合だけ紫色にする。

現在のタイルに通常候補がない場合、相対禁則・矢印無視候補の有無にかかわらず、そのカードをデッキへ戻してシャッフルし直すかを選べる。この引き直しはプレイヤーごとの1回引き直し権とは別で、回数制限はない。通常・相対禁則・矢印無視のいずれの候補もないカードは破棄し、デッキへ戻さず強制的に次のカードを引く。

追加ルール **「3辺接続時の矢印マッチング無視」** を有効にできる。矢印不一致候補は通常は表示しないが、タイルの3辺以上が既存タイルに隣接する場合だけ、地形接続・重なり・絶対禁則の条件を満たす候補を橙色で表示する。橙候補は回数制限なく選べる。確定時には矢印パターンのうち、隣接辺へ最も多く一致するものを記録する。

複数の既存タイルと接する候補では、上記のすべての接続条件を同時に満たさなければならない。

最初のタイルは開始タイルとしてランダムに1枚選び、盤面中央に配置する。開始時点では矢印パターンは未確定とする。

## 6. コマの配置

- コマは、今置いたタイルに描かれた都市・道・草原のいずれか1領域にだけ置ける。
- 接続済みの同一地形領域に、すでに誰かのコマがある場合、その領域には置けない。
- コマを置かないことも選べる。
- 完成した都市・道・修道院は得点化後にコマを持ち主へ返す。草原はゲーム終了時まで返さない。

草原についても都市・道と同様に、タイルをまたいで接続している草原領域全体で占有を判定する。草原の接続範囲はタイルを4小領域に分割した定義に基づいて求める。自分を含むいずれかのプレイヤーのコマがすでにある草原領域には、追加でコマを置けない。

## 7. 得点

都市・道・修道院・草原の完成条件と得点の詳細は `docs/scoring.md` を正とする。

## 8. ゲーム終了時の得点

- 未完成の都市・道に置かれたコマは、それぞれの終局得点を得る。
- 草原のコマは、隣接する完成都市1つにつき3点を得る。
- 草原のコマは終局採点後も盤面に残す（結果表示用）。

## 9. 頂点チップ

タイルの配置によって盤面上の頂点の周囲がすべてタイルで満たされたとき、そのタイルを配置したプレイヤーは頂点チップを1枚得る。同じ頂点から得られるチップは1枚だけとする。色の区別はなく、獲得個数だけを記録する。チップは終局得点の要素として表示・保持するが、初期版では得点換算を行わない。

## 10. 今後の拡張候補

- 紋章、交差点、橋などの得点修正
- 草原の終局得点
- タイルごとの希少度・追加タイルセット
