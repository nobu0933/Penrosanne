# ゲーム設定仕様（草案）

## 1. 目的と適用タイミング

ゲーム開始前に、対局のルール、盤面、参加者、表示テーマを設定できるようにする。設定は `GameConfig` としてゲーム状態とは別に保持し、対局開始時に確定する。

- ローカル対戦・ソロ：ゲームを開始する人が設定する。
- オンライン対戦：ルーム作成者（ホスト）だけが設定を変更できる。
- オンライン参加者：確定前の設定を閲覧できる。ホストが変更した設定は全員に同期する。
- 対局開始後：ゲームルールを変える設定は変更不可とする。対局を作り直す場合だけ再設定できる。

## 2. 開始前の設定項目

| 分類 | 項目 | 初期値 | 仕様 |
| --- | --- | --- | --- |
| 盤面 | タイル形状 | `rhombus` | 初期版では `rhombus`（ひし形）に固定する。山札には薄いひし形（シン）と厚いひし形（ファット）の両方を含む。凧形は将来の拡張候補。 |
| 表示 | テーマ | `meadow` | 地形・コマ・背景・UIの画像や配色を選ぶ。テーマはルールやタイル接続に影響しない。 |
| 山札 | 山札種類 | `standard` | 登録済みの `lite`（36枚）、`standard`（90枚）、`road-only`（42枚・道／交差点／修道院のみ）から選ぶ。ゲーム開始時にセレクターで選択する。 |
| 盤面 | タイル枚数 | 90枚 | 選択した山札種類により決まる。将来、山札から任意枚数を選ぶ設定を追加する。 |
| ルール | ミープル数 | 7個／人 | プレイヤーごとの初期コマ数。タイル枚数に応じた推奨値を表示するが、許容範囲内で手動変更できる。 |
| 拡張 | 修道院ルール | オフ | 修道院タイルを山札へ入れ、完成・得点ルールを有効化する。 |
| ルール | 草原ルール | オン | オフでは草原にミープルを置けず、草原得点も発生しない。 |
| 追加 | 引き直し | オン | 各プレイヤーは対局中に1回だけ、未配置タイルを破棄して新しいタイルを引ける。山札が空なら引き直せない。 |
| 手札 | 手札モード | `single` | 通常の1枚手札か、`private-city-planning`（私的な都市計画・公開手札3枚）を選ぶ。 |
| 追加 | 地形の左右反転 | `unlimited` | `unlimited` は通常・左右反転の両地形を毎手番の候補として判定し、仮置き後に何度でも選択できる。`disabled` は反転地形を候補に含めない。ミラー版は山札には含めない。 |
| ルール | 辺記号パターン | `both` | 通常・180度回転の両方を判定するか、通常のみを判定するかを選ぶ。 |
| ルール | 地形パターン | `both` | カード輪郭・辺記号とは独立して、地形・特徴領域を180度回転した状態も判定するか、通常のみを判定するかを選ぶ。 |
| ルール | マッチングルール | 通常 | 無視モードでは辺記号・頂点型制約・確定配置探索・絶対禁則を使わず、隣接辺の地形一致とタイル非重複だけを判定する。 |
| 称号 | 頂点王 | オフ | 頂点完成数が最多のプレイヤー全員に終局時10点。オンのときだけ頂点完成数を表示する。 |
| 称号 | 延伸王 | オフ | 所有して得点対象になった最長の道のタイル枚数が最多のプレイヤー全員に終局時10点。 |
| 称号 | 支援王 | オフ | 他プレイヤーに得点が入り自分には入らない地形完成の支援回数が最多のプレイヤー全員に終局時10点。 |
| 山札 | 引き方 | `random` | `random` はシン・ファットを含む山札から完全ランダムに1枚引く。`choose-shape` は、シン・ファットの候補を1枚ずつ提示し、片方を選ぶ。 |
| ソロ | CPU難易度 | `normal` | `easy` / `normal` / `hard`。ソロモードのみ表示する。 |
| マルチ | プレイ人数 | 2人 | オフライン／オンライン対戦で2〜4人から選ぶ。オンラインでは参加人数が満たされるまで開始できない。 |
| オンライン | 合言葉 | なし | ルーム参加時に照合する文字列。平文では保存・ログ出力しない。初期LAN版ではアクセス制限の補助であり、暗号化通信の代替ではない。 |

### タイル形状と引き方の補足

初期版の `choose-shape` は、シン用・ファット用の山札から候補を1枚ずつ提示し、プレイヤーが片方を選ぶ方式とする。選ばれなかった候補は対応する山札へ戻す。片方の山札が空の場合は、残っている山札から1枚だけを引く。

手札3枚を全員に公開して使う「私的な都市計画」モードは、ゲーム開始前の「手札モード」で通常モードと切り替える。詳細は [private-city-planning.md](private-city-planning.md) に定める。

## 3. 追加ルール：引き直し・地形の左右反転

各プレイヤーは対局ごとに1回、手番で引いた未配置タイルを破棄し、山札から新しいタイルを1枚引ける。山札が空なら引き直せず、盤面へ配置済みのタイルも対象にできない。引き直し権の消費有無にかかわらず、引き直したタイルは山札へ戻さない。

相対禁則と、3辺接続時の辺記号マッチング無視は採用しない。配置候補は地形接続、絶対禁則、辺記号、頂点型をすべて満たす通常候補だけである。

地形の左右反転は `unlimited` と `disabled` を開始時に選ぶ。`unlimited` では通常地形と左右反転地形の両方を候補生成し、同じ仮置き位置で選べる場合は盤面近くの反転ボタンで切り替える。反転地形は180度回転地形と独立なので、通常・反転のみ・180度回転のみ・反転かつ180度回転の4状態を判定する。`disabled` では反転した地形を候補に含めず、仮置き後も反転できない。手元タイルの反転ボタンは設けない。

引き直しの使用状況はプレイヤーごとの `redrawUsed` で管理する。地形の左右反転にはプレイヤー別の使用回数制限を設けない。

## 4. 設定画面の画面構成

1. モード選択（ソロ／オフライン対戦／オンライン）
2. 基本設定（形状、テーマ、タイル枚数、ミープル数、拡張ルール、引き方）
3. モード固有設定（CPU難易度、人数、オンラインのルーム名・合言葉）
4. 設定サマリーとゲーム開始ボタン

ルールに影響する変更を行った場合、画面にはタイル枚数・ミープル数・有効な拡張ルールの概要を常に表示する。

## 5. `GameConfig` のデータ例

```js
{
  mode: "solo", // "solo" | "local" | "online"
  tileShape: "rhombus",
  deckType: "standard", // "lite" (36枚) | "standard" (90枚) | "road-only" (42枚)
  themeId: "meadow",
  tileCount: 90,
  meeplesPerPlayer: 7,
  expansions: { monastery: false },
  specialActions: { redrawOnce: true, terrainMirrorMode: "unlimited" }, // "unlimited" | "disabled"
  matchingPatternMode: "both", // "both"（通常・180度回転） | "normal-only"（通常のみ）
  fieldRule: "enabled", // "enabled" | "disabled"（草原ミープル・草原得点をともに無効化）
  matchingRuleMode: "standard", // "standard" | "ignore"（地形接続・非重複のみ）
  titles: { vertexKing: false, roadKing: false, supportKing: false },
  terrainPatternMode: "both", // 辺記号とは独立。地形・特徴領域の通常・180度回転を判定するか
  drawMode: "random", // "random" | "choose-shape"
  playerCount: 2,
  cpu: { difficulty: "normal" },
  online: { roomName: "", passwordRequired: false },
  seed: "generated-at-game-start"
}
```

合言葉そのものは `GameConfig` や同期対象のゲーム状態に含めない。ホスト側のルーム情報として安全に照合する。

## 6. 対局中に変更できる項目

| 項目 | 対象 | 初期仕様 |
| --- | --- | --- |
| CPU高速化 | ソロ | CPUの思考待ち・演出待ちを短縮または省略する。評価ロジックと難易度は変えない。 |
| 確定得点表示 | 全モード | 各プレイヤーの現在の確定得点を常時表示する。終局得点の見込みは含めない。 |
| 配置可能位置表示 | 全モード | 現在のタイルの合法的な配置候補、およびコマを置ける領域をハイライトする。 |
| デバッグモード | 開発ビルド限定 | 引いた未配置タイルを任意のタイルへ差し替えられる。リリースビルドでは機能・UI・通信メッセージを含めて無効化する。 |

### CPU高速化

- `normal`：人間が確認できる短い待機時間を置く。
- `fast`：CPUの操作演出を省略し、決定後すぐ次の状態へ進める。
- CPUの評価処理が重い場合は、将来 `fast` で候補探索の上限を調整できる。ただし難易度の意味が変わるため、その場合は別設定として明示する。

### 配置可能位置表示

- タイルの回転ごとに合法配置を計算する。
- 現在選んでいる回転の候補だけを標準表示する。
- コマ配置フェーズでは、コマを置ける特徴領域だけを表示する。
- 表示は補助であり、合法性の最終判定は常に `Rules` が行う。

### デバッグモード

- 有効化はURLパラメータや開発用ビルド設定でのみ可能にする。
- オンライン対戦では通常は無効とする。オンライン検証が必要な場合だけ、ホスト限定で有効にできる。
- タイル差し替えは操作履歴に残し、再現テストに利用できるようにする。
