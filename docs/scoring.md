# 得点・完成判定仕様（草案）

## 1. 共通規則

- 連結した同じ特徴領域に複数プレイヤーのミープルがある場合、最も多くミープルを置いているプレイヤー全員が得点を得る。
- 完成した都市・道・修道院に置かれたミープルは、得点後に持ち主へ返す。
- 草原はゲーム中に完成せず、草原のミープルはゲーム終了まで盤面に残る。

## 2. 都市

### 完成条件

連結した都市の外周にあるすべての都市辺が、他タイルの都市辺と接続しているとき完成する。都市が輪になり、開いた都市辺がなくなった場合も完成とする。

### 得点

| 状態 | 得点 |
| --- | --- |
| 完成時 | `(都市を構成するユニークなタイル数 + 紋章数) × 2` |
| 終局時に未完成 | `(都市を構成するユニークなタイル数 + 紋章数) × 1` |

紋章を得点に含めないモードは後から追加する。このモードが有効な場合、上式の紋章数を0として計算する。

## 3. 道

### 完成条件

道の両端が都市・交差点・修道院のいずれかに接続したとき完成する。交差点と修道院は道の終端であり、タイル内の道路を相互接続しない。外部タイルを経由して連結した結果、同じ道になることはある。道が輪になり、開いた道端がなくなった場合も完成とする。

### 得点

| 状態 | 得点 |
| --- | --- |
| 完成時 | 道を構成するユニークなタイル数 × 1 |
| 終局時に未完成 | 道を構成するユニークなタイル数 × 1 |

## 4. 修道院

- 修道院タイルの4頂点それぞれで、接する全タイルの内角合計が360度となり、周囲に隙間がないとき完成する。
- 完成時の得点は、修道院タイル自身と、周囲で頂点が接しているユニークなタイル数の合計。
- 終局時に未完成の場合も、修道院自身を含む同じ枚数を得る。

## 5. 草原（拡張ルール有効時）

- 草原は完成せず、ゲーム終了時だけ得点を計算する。
- 連結した草原にミープルが1人だけなら、そのプレイヤーが所有者となる。
- 複数プレイヤーのミープルがある場合、最も多いプレイヤー全員が所有者となる。
- 草原の所有者は、その草原に隣接する**完成した都市1つにつき3点**を得る。
- 同じ完成都市が草原の複数箇所に隣接していても、数えるのは1都市とする。
- 草原の連結範囲は、各タイルを①〜④の小領域に分割した `fieldScoreGroups` で決める。タイル間は共有辺の両側が草原または道の場合だけ接続し、都市辺は得点用草原を接続しない。

## 6. 終局時の得点内訳

- 各得点は、プレイヤー、特徴種別、点数、得点時点（完成時／終局時）を記録する。
- 終局画面では、プレイヤーごとに合計点とこの内訳を表示する。

## 7. 称号（開始前に個別選択）

初期状態ではすべてオフ。オンにした称号について、最多記録が1以上なら同率首位の全プレイヤーにそれぞれ10点を加える。称号は地形の完成得点・終局得点とは別の得点内訳とする。

| 称号 | 比較する記録 |
| --- | --- |
| 頂点王 | 各プレイヤーの頂点完成数。タイル配置で周囲360度が埋まった頂点を、その配置者に1回だけ加算する。 |
| 延伸王 | 所有して得点対象になった道のうち、最長の道のタイル枚数。完成済み・終局時に未完成の道を含む。所有者はその道の最多ミープル数で判定し、同数なら全員が所有者となる。 |
| 支援王 | 自分の配置によって、他プレイヤーが既に所有していた都市・道・修道院を完成させた回数。完成時に他プレイヤーへ得点が入り、配置者自身には得点が入らなかった地形だけを数える。配置者のミープルが同じ地形にあっても、この得点条件を満たせば数える。 |

終局の得点詳細には称号ごとに「称号：頂点王 +10」などと表示する。プレイヤー情報には通常の終局得点に続いて、獲得称号の合計を「称号+10」のように表示する。頂点王がオフの対局では頂点完成数を表示しない。

プレイヤー情報には支援回数も表示する。対局中は、有効な称号のアイコン下に暫定首位のプレイヤー色で「+10」を表示する。同率首位なら全員分を縦に表示し、全員の記録が0なら表示しない。延伸王の暫定判定では、既に得点対象となった道に加えて、現在ミープルを置いて所有している未完成の道の長さも数える。アイコンを押すと称号条件と終局時の10点加算を確認できる。
